# Tinkora

**Small fixes, smoother classes.**

Tinkora is a small campus technology-support service. Students and teachers can report classroom technology problems and see each report's current status.

## Mission 12, Chapter 1

This repository is the case file for a guided code-reading and debugging lesson.

- `starter` contains three intentional issues.
- `chapter-1-complete` contains the verified result.
- No external database, API key, or account is required.

## Run the starter

1. Install Node.js 18 or newer.
2. Open a terminal in this folder.
3. Run `npm start`.
4. Open `http://localhost:3000`.

Expected terminal message:

```text
Tinkora is ready at http://localhost:3000
```

## The three guided issues

1. The frontend sends `problem`, but the backend expects `title`.
2. The renderer reads `ticket.name`, but each ticket contains `title`.
3. The Refresh button has no click listener.

Follow the lesson in order. Do not copy the completed branch before completing the investigation.
